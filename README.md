### TrajectoryTracker - Tennis Clip Analyzer (In Progress)
 - Tracks the ball from a video clip of a tennis rally
 - Uses the tracked image coordinates to reconstruct the ball's trajectory in 3D
 - Estimates the initial launch speed and spin of the ball from the reconstructed 3D trajectory
 - Reconstruction model trained using a synthetic dataset generated using a physics simulator
 - Built with Python & associated libraries - PyTorch, NumPy, Pandas, OpenCV, Matplotlib, etc.
 - Link to repo: https://github.com/Mymy-T/TrajectoryTracker/tree/main

  ### StudyQB - Quizbowl Study App
 - AI analysis of questions from the [QBReader database](https://www.qbreader.org/db/) for common clues
 - Store cards, personal notes, and clues
 - Various review modes, such as spaced repetition, buzz-in mode, gradual clue reveal, and more
 - Embedded [frequency lists](https://www.qbreader.org/db/frequency-list/) to help decide what to study
 - Track progress & weak spots with individual card review statistics
 - Built mainly with Swift (iOS) & Kotlin (Android); also incorporates LLMs via Groq API for on-demand model analysis and Python to create a cached dataset
 - Link to repo: https://github.com/Mymy-T/Study-QB
